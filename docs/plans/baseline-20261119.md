## 7. وسم الاسترجاع وحدود لقطة الأساس

- **الوسم المطلوب:** pre-consolidation-20261119 → main SHA 9606113b48a29801961cfdeab662974fdc6ecb7e.
- **نتيجة القراءة:** GitHub GET للوسم أعاد 404 وقت التقاط الأساس — الوسم **غير موجود**.
- **حالة الإنشاء:** محجوبة؛ موصل GitHub المتاح لا يوفّر فعل create_tag أو create_ref لوسوم Git، وcreate_branch ليس وسمًا. لا يُدّعى تحقق الشرط.
- هذه الوثيقة محفوظة مبدئيًا في فرع PR المرحلة 0؛ **لا دمج ولا انتقال لمرحلة 1** قبل تحقق الوسم والاختبارات وبوابة الخروج.
