# Performance Analytics
## Workflow
1. Prefer authorized Google Search Console query/page data for clicks, impressions, CTR and average position; identify property, country, device, language and window.
2. Add GA4 or privacy-respecting event analytics only when approved. Measure WhatsApp link clicks, submitted lead forms, qualified conversations and signed contracts separately.
3. Do not infer customers from visits or button clicks. Separate organic search, referral, direct, paid ads and unknown attribution.
4. AI citation tracking is sampled research; log exact prompt, engine, date and URLs, and show uncertainty.
5. Produce period-on-period analysis using compatible definitions, sufficient sample sizes and actual timestamps. Note data lag and sampling.
6. Recommend efforts by qualified-lead impact and implementation cost, not vanity volume. Never invent missing metrics.
## Output
Metric dictionary; source and access status; baseline; time window; actual values or unavailable; trend; confidence; next experiment and expected measurement.
